# Savely Android

APK firmati e note di versione dell’app Android nativa di Savely.

Versione corrente: [0.1.9-alpha](https://github.com/GoryNickel9/Savely-Android-Releases/releases/tag/v0.1.9-alpha), versionCode 10. Include APK, checksum, note e rapporto di validazione. Passano 503 test JVM e due suite complete da 130 casi ciascuna su Android 12 e 15. Parità globale e flussi reali account/Coppia/Admin restano da qualificare; i limiti sono dichiarati nel rapporto.

La prima installazione sopra la 0.1.7 richiede il download manuale; dalla 0.1.8 la schermata aggiornamenti consulta questa repository pubblica.

Scarica l’APK dalla pagina [Releases](https://github.com/GoryNickel9/Savely-Android-Releases/releases). Android chiederà di autorizzare l’installazione dalla sorgente scelta. Gli aggiornamenti usano la stessa firma e una versione superiore per conservare i dati locali.

Le versioni alpha sono anteprime. Le note indicano i controlli eseguiti e i limiti ancora aperti. Verifica il file SHA-256 prima dell’installazione.

Questa repository pubblica contiene distribuzioni e metadati. I sorgenti sono mantenuti separatamente. L’APK include i font Inter e Space Grotesk con le rispettive licenze SIL Open Font License.
